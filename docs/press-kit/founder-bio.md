## 200-word bio

`@JanSol0s` is the open-source contributor behind **Grok Agent OS**, the Windows-first distribution and runtime layer for Grok agents on X. Working under the `AgentMindCloud` GitHub organization, JanSol0s designed and shipped the v2.15 unified manifest standard, a 33-check Agent Constitution scanner, a PowerShell-first CLI, and the Next.js marketplace that catalogs every shipped agent — all under Apache 2.0.

The project is built deliberately as an ecosystem ally to xAI: it is the runtime layer xAI has not shipped yet, not a competitor. JanSol0s positions every release that way, in code and in copy.

By May 2026, eleven production-grade agents had landed in the repo: four X Money tools that solve real creator pain on X's payments product, three flagship Super Agents (Living Narrative Fabric, Self-Evolving Personal OS, Cross-Reality Action Fabric), and four lighter Super Agents focused on swarms, provenance, contradiction detection, and zero-config goal execution. Twenty-two creator templates ship alongside them.

JanSol0s ships from a Windows 11 + PowerShell development environment, treats local-first and privacy-first as defaults, and runs the project's safety scanner in CI on every commit so trust is enforceable, not aspirational.

## AgentMindCloud — organization paragraph

`AgentMindCloud` is the GitHub organization that publishes **Grok Agent OS** and a small constellation of related open-source tools for the xAI / X / Grok ecosystem. Everything the org ships is Apache 2.0, Windows-first by default, and explicitly framed as ecosystem-ally infrastructure — never a competitor to xAI. Beyond the flagship `grok-agent` repo, the org maintains the `grok-pulse-mcp-server` (an MCP-compatible attention server for builders juggling multiple repos) and the `x-platform-toolkit` (a 20-tool monorepo for X creators). Both are folded into `grok-agent` as `git subtree` packages so the entire ecosystem ships from a single source of truth, with provenance preserved in `MERGE_PLAN.md`.
