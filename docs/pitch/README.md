# `docs/pitch/` — Outbound Briefing Documents

Built for xAI, X, Grok and the ecosystem community. ❤️

This folder holds the formal, outbound-facing documents Grok Agent OS uses to
brief partners — primarily xAI engineering, X platform, and Grok product
teams — on where the standard is going next and how they can shape it.

## What's inside (v0.1)

| File | Purpose | Audience |
|---|---|---|
| `xai-partnership-pitch.md` | Top-of-funnel pitch for the broader xAI partnership | xAI BD + leadership |
| `60-second-demo-script.md` | Voice-over script for the launch demo | Internal + xAI demo |
| `v2.16-rfc.md` | **Formal RFC for the next manifest spec version (v2.16). Inviting xAI co-authorship.** | xAI engineering review |

## What's coming next

Future pitches — quarterly RFCs (v2.17, v2.18, ...), governance proposals,
and partner-specific briefings — will live here under predictable filenames.
Each pitch is written as a starting point for xAI input, never a finished
design. We are the distribution + runtime layer xAI has not shipped yet, and
this folder is where we hand the mic to xAI engineers.

The current spec lives at `spec/v2.15/grok-agent.yaml`. The Constitution
lives at `safety/constitution.md`. The validator is `safety/scanner.py`.
