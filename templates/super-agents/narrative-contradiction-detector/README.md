# Narrative Contradiction Detector

**Lighter Super Agent for Grok Agent OS**

Actively hunts for contradictions across X, news, government data, academic sources, and personal memory, then presents them with evidence and asks the user which version of reality to explore — surfacing hidden conflicts instead of smoothing them over.

## Key Features

- Real-time contradiction scanning across multiple source types
- Evidence-backed conflict reports with primary links
- "Choose your narrative" mode for user-guided exploration
- Versioned reality tracking
- Equal-rigor presentation of all sides

## Installation (Windows 11)

```powershell
.\cli\grok-agent.ps1 install templates/super-agents/narrative-contradiction-detector/grok-agent.yaml
```

Or post the manifest on X with the text `grok install this`.

## Usage

```powershell
.\cli\grok-agent.ps1 run narrative-contradiction-detector "Summarize the current debate around AI regulation in the EU and US"
```

The agent returns a clear map of contradictions, evidence for each side, and an invitation to dive deeper into any narrative branch.

## Technical Notes

- Integrates X search, news APIs, and academic search out of the box
- Cost limit: $1.00 per session (configurable in manifest)
- Ideal for research, journalism, policy analysis, and truth-seeking workflows
