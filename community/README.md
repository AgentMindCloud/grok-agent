# `community/` — Public-facing community runbooks

> Built for xAI, X, Grok and the ecosystem community. ❤️

This folder holds the source-of-truth runbooks for the Grok Agent OS public
community surfaces (Discord, X spaces, GitHub Discussions). Every change to
how the community is moderated, what channels exist, what roles can do what,
or how automation posts into community spaces lands here first as a PR before
it goes live.

## Contents

- [`discord-bootstrap.md`](./discord-bootstrap.md) — Discord channel layout,
  role grants, welcome message template, posting guidelines (with the
  finance and real-world-action disclaimers from CLAUDE.md §12),
  moderation playbook, and a pointer to the auto-posted curation digest
  workflow at `.github/workflows/discord-post-curation.yml`.

## Related runbooks elsewhere in the repo

- [`/CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) — applies to every
  community surface, not just Discord.
- [`/CLAUDE.md`](../CLAUDE.md) — the Hard Six, the forbidden-phrases
  list, and the finance / tax / real-world-action disclaimer wording.
- [`/safety/constitution.md`](../safety/constitution.md) — the Agent
  Constitution every shipped agent has to satisfy.
